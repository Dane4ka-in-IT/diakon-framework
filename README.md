# Лабораторная работа: Создание нейросетевого фреймворка DIAKON-FRAMEWORK

## Общие сведения
**Проект:** DIAKON-FRAMEWORK — это распределенная микросервисная платформа для проектирования, обучения и анализа нейронных сетей в режиме No-Code. Платформа реализует математический фундамент Deep Learning (слои, оптимизаторы, лоссы) с использованием чистого NumPy, обеспечивая полную прозрачность вычислений для образовательных целей.

## 1. Архитектура и компонентный анализ
Система спроектирована по модульному принципу, где каждый микросервис инкапсулирует свою зону ответственности.

### **1.1. Java-Backend (Control Unit)**
Центральный узел на базе **Spring Boot 3** (порт `1000`), отвечающий за сохранение состояний (Persistence) и координацию вычислительных задач.

*   **`UserController` & `UserService`**: Управление жизненным циклом пользователей (регистрация, BCrypt-аутентификация). Реализация бизнес-логики контроля лимитов и PRO-статуса (разблокировка глубокого обучения свыше 20 эпох).
*   **`TrainingTaskService`**: Асинхронное управление очередями задач обучения. При получении конфигурации от фронтенда создает сущность `TrainingTask`, сохраняет её в **PostgreSQL** и инициирует HTTP-вызов к AI-ядру.
*   **`AiClient`**: Реализован через `RestTemplate`. Поскольку контейнеры разделяют сетевой стек (`network_mode: "service:python-logic"`), взаимодействие идет напрямую по `http://localhost:8000`.
*   **`init_db/`**: Скрипты автоматической инициализации таблиц пользователей и моделей (SQL).

### **1.2. Python AI Engine**
Вычислительное ядро на базе **FastAPI** (порт `8000`), реализующее математику «под капотом».

*   **`engine.py`**: Основа фреймворка. Реализует абстрактный класс `Layer`, полносвязные слои (`Dense`), преобразователи размерности (`Flatten`) и сверточные алгоритмы (`Conv2D`). Весь Forward и Backward propagation реализованы на чистом NumPy (скалярные произведения, градиент по весам и входам).
*   **`advanced_layers.py`**: Содержит механизмы повышения обобщающей способности модели — `Dropout` (случайное отключение весов) и `BatchNorm1d` (нормализация активаций). Работают внутри Core API.
*   **`optimizers.py`**: Реализация стратегий обновления весов: классический `SGD`, `Momentum` (накопление инерции) и `GradClipper` (защита от "взрывающихся" градиентов).
*   **`callbacks.py`**: Управляющие сигналы обучения: `EarlyStopping` (прекращение при отсутствии прогресса) и динамическое изменение шага обучения.
*   **`losses.py`**: Математика функций потерь — `MSE` для регрессии и `Cross-Entropy` для многоклассовой классификации.

### **1.3. Frontend Dashboard**
Построен на **React 18** (Vite + TS) (порт `5173`). Основной функционал:
*   **MLP Builder**: Генерирует JSON-конфигурацию нейросети на основе положения слайдеров и дропдаунов.
*   **Chart.js Integration**: Динамическая отрисовка Loss Curve на основе данных, поступающих из БД через Long Polling.

## 2. Слой Core API vs SaaS Interface
Архитектура Core Engine является более универсальной, чем текущая SaaS-оболочка.

| Компонент | Поддерживается Core Engine | Доступно в UI (SaaS) |
| :--- | :---: | :---: |
| **Dense Layers** | ✅ | ✅ |
| **Conv2D / Flatten** | ✅ | ❌ |
| **Dropout / BatchNorm** | ✅ | ❌ |
| **Relu / Sigmoid / Softmax**| ✅ | ✅ |
| **SGD / Momentum** | ✅ | ✅ |

*Важно: Ядро фреймворка готово к расширению до полноценных CNN (SqueezeNet-like) структур без доработки вычислительных методов.*

## 3. Исследование нейросетевых феноменов
Поскольку всё ядро написано с нуля, DIAKON-FRAMEWORK позволяет изучать «честную» математику процесса:
1.  **Проблема Dying ReLU**: На графиках обучения наглядно видно замирание градиента при неверном выборе Learning Rate.
2.  **Эффект Momentum**: Возможность сравнить стабильность сходимости при прохождении локальных минимумов.
3.  **Exploding Gradients**: Демонстрация необходимости клиппинга в глубоких MLP на сложных датасетах (MNIST).

## Приложение А: Руководство по развертыванию
*(Данный раздел предназначен для первичного запуска системы в локальном окружении).*

### А.1. Подготовка
1.  Установите **JDK 17** (с правами администратора) и перезапустите терминал.
2.  Установите Docker Desktop.
3.  Для сборки Java-артефакта перейдите в `java-backend/NoCodePlatform` и выполните `.\mvnw.cmd clean package`. Дождитесь `BUILD SUCCESS`.

### А.2. Старт через Docker Compose
1.  **Отключите VPN** перед скачиванием образов (особенно Python-логики).
2.  Выполните в корне репозитория: `docker-compose up -d --build`.
3.  Если Java упал с ошибкой подключения к БД при первом старте — подождите 15 секунд и выполните `docker-compose up -d`.

**Точки входа:**
*   **Frontend**: `http://localhost:5173`
*   **Java API**: `http://localhost:1000`
*   **PostgreSQL**: `localhost:6666`
