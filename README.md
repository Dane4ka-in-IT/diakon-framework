## 1. Архитектура системы (Enterprise NoCode)
В отличие от классических скриптовых решений, проект реализован в виде распределенной микросервисной SaaS-платформы, упакованной в Docker. Это обеспечивает строгую изоляцию слоев:

*   **Java Backend (Spring Boot 3 / PostgreSQL):** Выступает в роли Оркестратора. Управляет очередями задач, хранит историю экспериментов (Persistence), реализует систему лимитов и монетизации (PRO-подписки). Асинхронно коммуницирует с математическим ядром.
*   **Python AI Engine (FastAPI / NumPy):** Математическое ядро фреймворка. Реализовано на чистом NumPy (без TensorFlow/PyTorch) для глубокого понимания тензорных операций.
*   **Web Frontend (React / Chart.js):** Высокопроизводительный интерактивный дашборд для визуального конструирования топологии сети (MLP Builder), трекинга градиентного спуска и интерактивного тестирования моделей (включая Canvas для рисования цифр).

## 2. Реализованный математический аппарат (Python Core)

Фреймворк спроектирован по модульному принципу. Стоит отметить, что через Web-интерфейс (NoCode) пользователю доступен конструктор полносвязных сетей (согласно ТЗ), однако **ядро фреймворка (Core API) поддерживает расширенные архитектуры**:

### 2.1. Продвинутые слои (Core API)
*   **Conv2D:** Алгоритм классической двумерной свертки с поддержкой многоканальных тензоров и автоматическим расчетом градиентов по ядрам ($dW$) и смещениям ($db$).
*   **BatchNorm1d:** Пакетная нормализация для стабилизации распределения признаков внутри мини-батчей.
*   **Dropout:** Слой регуляризации для предотвращения переобучения путем случайного отключения нейронов.

### 2.2. Оптимизаторы
Фреймворк поддерживает три стратегии минимизации ошибки:
1.  **SGD (Stochastic Gradient Descent):** Классическое обновление весов пропорционально антиградиенту.
2.  **Momentum:** Накопление «инерции» градиентов для ускорения сходимости и преодоления локальных минимумов.
3.  **Gradient Clipping:** Принудительное отсечение нормы градиента, защищающее архитектуру от математических переполнений.

### 2.3. Функции активации и потерь
*   **ReLU & Sigmoid:** Базовые активации для скрытых слоев.
*   **Softmax:** Преобразование логитов в вероятностное распределение (используется для MNIST).
*   **MSE & Cross-Entropy:** Функции потерь для задач регрессии и многоклассовой классификации.

## 3. Анализ процесса обучения и аномалий

Поскольку фреймворк написан с нуля без использования "индустриальных костылей" (таких как Xavier/He инициализация или адаптивный оптимизатор Adam), система позволяет наглядно изучать классические проблемы Deep Learning:

1.  **Взрыв градиента (Exploding Gradient):** На графиках обучения (например, датасет Iris при высоком Learning Rate) можно наблюдать, как Loss долгое время находится на плато, а затем резко уходит вверх. Это демонстрирует накопление ошибки в алгоритме Momentum без клиппинга.
2.  **Затухание градиента / Dying ReLU:** При обучении сложных данных (MNIST 8x8) сеть может застревать на высоком показателе Loss (например, 14.4). Это классическая демонстрация того, почему полносвязные сети (Dense) хуже подходят для CV-задач, чем сверточные (CNN), и почему важна нормализация входных тензоров.
3.  **Осцилляция (Custom Dataset):** На случайно сгенерированных данных функция потерь демонстрирует идеальный "шум" (осцилляцию), доказывая, что модель честно пытается найти закономерности там, где их математически нет.

## 4. Руководство пользователя (Запуск)

### 4.1. Развертывание через Docker
Система полностью контейнеризирована:
```bash
docker-compose up -d --build
```
*   **Frontend UI:** `http://localhost:5173`
*   **Java Backend API:** `http://localhost:8888`
*   **PostgreSQL:** `:6666`
*   **Python AI Engine:** Внутренний микросервис

### 4.2. E2E Сценарий использования
1.  **Авторизация:** Создайте аккаунт. Для снятия лимита в 20 эпох необходимо активировать PRO-статус.
2.  **Топология:** Выберите набор данных (Iris / MNIST). Сконфигурируйте скрытые слои (ползунками) и шаг обучения. Блок "Топология" обновится автоматически.
3.  **Тренинг:** Нажмите «СТАРТ». Java-сервер асинхронно запустит вычисления, а Frontend начнет отрисовку кривой Loss. Эксперимент будет сохранен в БД.
4.  **Инференс:** После статуса `COMPLETED`, используйте "Модуль предсказаний". Для Iris введите параметры лепестков, для MNIST — нарисуйте цифру мышью в сетке 8x8.
