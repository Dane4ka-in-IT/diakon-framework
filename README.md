# DIAKON-FRAMEWORK: Микросервисная No-Code AI Платформа

Это учебный проект, демонстрирующий создание полноценной **No-Code платформы для машинного обучения** с использованием микросервисной архитектуры. Система позволяет пользователям визуально конструировать, обучать и тестировать нейронные сети через веб-интерфейс, без написания кода.

Основной упор в проекте сделан на **архитектуру и разработку Enterprise-бэкенда на Java/Spring Boot**, который выступает в роли оркестратора для вычислительного ядра на Python.

## ☕ Java Backend (Spring Boot 3) - Ядро системы

Это центральный компонент платформы, отвечающий за всю бизнес-логику, управление данными и координацию других сервисов.

*   **REST API:** Разработан полноценный API для управления пользователями и задачами обучения.
*   **Асинхронное выполнение задач:** Для запуска долгих процессов обучения (которые выполняет Python-сервис) используется `CompletableFuture`. Это позволяет не блокировать основной поток и моментально отдавать ответ пользователю, обеспечивая отзывчивость интерфейса.
*   **Работа с базой данных (JPA/Hibernate + PostgreSQL):** Реализована персистентность данных: хранение пользователей, истории экспериментов, конфигураций моделей и результатов обучения.
*   **Аутентификация и Бизнес-логика:** Внедрена система регистрации и входа пользователей с хэшированием паролей (BCrypt), а также реализована логика "PRO-подписки", которая снимает ограничения на количество эпох обучения.
*   **Docker-контейнеризация:** Бэкенд полностью готов к развертыванию, упакован в Docker-контейнер.

---

## Что еще под капотом?

*   **🐍 Python AI Engine (FastAPI & NumPy):** Вычислительное ядро, написанное с нуля на чистом NumPy. Реализует математику нейронных сетей (слои, оптимизаторы, лоссы) и обернуто в REST API, которое потребляет Java-сервис.

*   **⚛️ Frontend (React & TypeScript):** Интерактивный дашборд для визуального конструирования сетей, отрисовки графиков обучения в реальном времени (Chart.js) и тестирования моделей через Canvas API (рисование цифр).

---

## Технологический стек

*   **Backend:** Java 17, Spring Boot 3, Spring Data JPA, Spring Security
*   **База данных:** PostgreSQL
*   **AI Engine:** Python 3.8, FastAPI, NumPy
*   **Frontend:** React, TypeScript, Vite, Chart.js, Tailwind CSS
*   **Инфраструктура:** Docker, Docker Compose

---

## Архитектура системы

Платформа следует классической микросервисной схеме:

`Пользователь (React) ➔ Java Backend (Spring Boot) ➔ Python AI Engine (FastAPI)`

При этом Java-бэкенд является единственным "владельцем" базы данных:

`Java Backend ⇄ PostgreSQL`
